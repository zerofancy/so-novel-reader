# 阅读器书签功能 Spec

状态：已实现；最新验证记录见同目录 `reader-bookmarks.html`  
日期：2026-10-05

## 1. 目标与范围

用户可以在阅读过程中保存当前位置、为书签命名，并从当前书的书签列表返回该位置继续阅读。现有章节列表底部面板改为「目录 / 书签」双 tab，保留目录原有行为。

首版包含新增、查看、跳转、重命名、删除和本地持久化；覆盖滚动（SCROLL）、分页（PAGED）、仿真翻页（FLIP）三种模式。不包含云同步、书签导入导出、正文划线、笔记或全文搜索。

## 2. 现有实现依据

- `ReaderScreen.kt` 使用 `ModalBottomSheet` 展示目录；点击目录通过 `goToChapter` 跳转，并使用 `pendingFragment` 与 `jumpToken` 驱动正文定位。
- `ReaderLocator` 保存 `chapterHref`、`chapterIndex`、`chapterFraction`。`ReaderContent.positionAt/progressAt` 按正文块权重映射进度，进度不是像素偏移或屏幕页码。
- `ReaderViewModel` 管理章节加载和阅读进度，常规进度保存有 500ms 防抖。新增书签必须读取当前内存位置，不能读取可能滞后的已保存进度。
- Room `LibraryDatabase` 当前为版本 2，已配置 `1 → 2` AutoMigration；阅读进度通过书籍外键级联删除。

## 3. 用户交互

### 3.1 新增书签

1. 用户点击正文显示阅读控制栏，顶部工具栏提供「添加书签」图标，原目录入口保留。
2. 点击入口时立即捕获当前书、章节及可见正文位置的快照，再打开命名对话框。命名期间的翻页或朗读进度变化不改变待保存位置。
3. 对话框标题为「添加书签」，名称默认填入当前章节标题（无标题时使用「第 N 章」），文本可编辑；提供「取消」「保存」。
4. 名称去除首尾空白后需包含非空白字符，长度为 1–50 个 Unicode 码点；超长或空白时显示字段错误且不可保存。默认名称超过上限时截断。
5. 保存成功关闭对话框，提示「书签已保存」，保持原阅读位置。取消不写入数据库。
6. 保存过程中禁止重复提交；写入失败保留名称与位置快照，显示「保存失败，请重试」。正文未加载完成或正在跳转时，添加入口禁用。

允许同名书签，同一本书、同一章节内的同一位置只能保存一个书签（进度误差不超过 0.000001 视为同一位置）。重复添加提示「该位置已有书签，可在书签列表中重命名」，不创建记录；检查与插入在同一数据库事务中执行，防止并发重复。

### 3.2 双 tab 面板

- 目录入口打开现有底部面板，顶部显示「目录」「书签」两个 tab，首次打开默认选中「目录」。同一阅读会话内记住最近选择，重进阅读器默认恢复「目录」。
- 「目录」保留层级、当前章节高亮、自动定位当前章节及章节锚点跳转；仅切换到目录时执行定位，书签更新不得触发目录滚动。
- 「书签」只展示当前 `bookId` 的记录，按 `createdAt DESC, id DESC` 排序，重命名不改变顺序。两个列表分别保存滚动状态。
- 每行主文本为书签名称，最多两行并省略；辅助文本展示章节标题及章节内进度百分比，右侧提供「更多」菜单。列表支持滚动，不设人为数量上限。
- 空状态显示「还没有书签」及「阅读时点击添加书签，记录当前位置」。无目录的书也能正常使用书签 tab。
- 点击书签行发起跳转；「更多」菜单提供「重命名」「删除」，菜单操作不触发行点击。
- 列表加载、读取失败和空列表分别展示独立状态；失败提供「重试」，不能误显示为空列表。

### 3.3 跳转与继续阅读

1. 使用书签的 `chapterHref` 在当前书的章节列表中解析目标；`chapterIndex` 仅作辅助展示，不在地址失效时静默跳到其他章节。
2. 对目标章节加载成功并应用书签位置后关闭面板，正文展示目标位置，更新并立即保存当前阅读进度；书签记录本身保持不变。
3. 同章跳转也必须触发重新定位，包括重复点击同一书签。清除旧 `pendingFragment`，通过新的跳转请求标识（沿用或扩展 `jumpToken`）驱动三种阅读器。
4. 仅在目标位置随目标内容一起准备好后发布新的跳转标识，防止旧章节或旧进度提前响应；跳转期间忽略旧视图的进度回调。连续点击时取消旧请求，最终以最后一次点击为准。
5. 当前书正在朗读时，主动跳转先暂停朗读并挂起自动跟随，避免语音定位把正文拉回；跳转成功后保持暂停，用户点击播放时从新的位置开始朗读。其他书的后台朗读不受影响。
6. 目标地址不存在时显示「书签位置已失效」，保留书签供重命名或删除。章节读取失败显示「无法打开书签位置，请重试」，保留面板、书签和原阅读位置，不写入失败目标的阅读进度。

位置语义：书签记录当前可见正文的起点。滚动模式返回该正文位置附近；分页与仿真翻页模式返回包含该位置的页面。字体、屏幕大小或阅读模式改变后仍按正文位置定位，不承诺恢复旧屏幕页码或精确像素。图文混排使用现有正文块进度映射；图片书签定位到对应图片块。

### 3.4 管理与生命周期

- 重命名复用新增时的名称校验；取消不修改，保存只修改名称和 `updatedAt`，不改变目标位置或 `createdAt`。
- 删除先展示确认对话框「删除书签『名称』？」；成功后刷新列表，失败提示并保留记录。
- 返回书架、重启应用或切换阅读模式后书签仍存在；不同书籍的书签互不混用。
- 删除书籍时级联删除其书签。删除后重新导入视为新书，不恢复旧书签；相同文件的重复导入若复用原 `bookId`，保留原书签。

## 4. 数据设计

新增 `BookmarkEntity`，表名 `bookmarks`：

| 字段 | 类型 | 约束 / 用途 |
| --- | --- | --- |
| id | String | 主键，UUID |
| bookId | String | 非空，外键关联 `books.id`，`ON DELETE CASCADE` |
| name | String | 非空，应用层执行名称校验 |
| chapterHref | String | 非空，定位章节的主要依据 |
| chapterIndex | Int | 创建时的章节序号，从 0 开始 |
| chapterTitle | String | 创建时的章节标题，用于列表展示 |
| chapterFraction | Float | 有限数值，范围 `[0, 1]`，正文权重进度 |
| createdAt | Long | 创建时间，epoch milliseconds |
| updatedAt | Long | 最近修改时间，epoch milliseconds |

建立 `(bookId, createdAt, id)` 非唯一复合索引，支持按书查询和稳定排序，其首列也覆盖外键索引需求。名称不设唯一约束；位置通过 DAO 事务执行重复检查，无需变更数据库 schema。

新增 `BookmarkDao` 与 `BookmarkRepository`：观察当前书列表（`Flow`）、新增、重命名、删除。所有查询与更新均限定 `bookId`；重命名与删除同时校验 `id`，避免操作其他书的记录。数据库 I/O 在后台执行，UI 在写入成功后提示，列表以数据库 Flow 为准。

### 数据库升级

- `LibraryDatabase` 升为版本 3，加入 `BookmarkEntity` 和 DAO。
- 保留 `AutoMigration(from = 1, to = 2)`，新增 `AutoMigration(from = 2, to = 3)`，由 Room/KSP 生成新增表、索引和外键的迁移。
- 导出并提交 `app/schemas/.../3.json`。本次仅增加表，无需手写 `Migration` 或 `AutoMigrationSpec`；不得使用破坏性迁移替代。
- 验证 `2 → 3` 和 `1 → 3` 完整迁移路径，已有书籍、分类和阅读进度保持不变。

## 5. 实现安排

1. 数据层：新增实体、DAO、Repository、数据库版本与 schema；在 `AppContainer` 中注入 Repository。
2. 状态层：`ReaderViewModel` 订阅当前书书签，提供增删改与跳转事件，增加列表加载/错误及写入状态。捕获位置与命名表单解耦，避免表单修改定位快照。
3. 跳转层：复用章节缓存与加载逻辑，补齐同章定位、请求取消及失败回退。让目标内容、目标 locator 和跳转请求标识一致发布；仅成功跳转才覆盖阅读进度。
4. UI 层：将现有目录面板提取为带双 tab 的组件；加入命名对话框、列表行、更多菜单、删除确认与错误反馈。紧凑屏幕下保证顶部操作可见且触控区域至少 48dp；图标和菜单提供中文无障碍描述。
5. 三种阅读模式均验证可见位置上报及跳转标识响应。若现有上报粒度无法满足正文起点语义，补充位置上报；不要用页码代替正文进度。

## 6. 验收与测试

| 场景 | 验收结果 |
| --- | --- |
| 新增并命名 | 在正文中部创建后，书签 tab 显示指定名称和章节信息，阅读位置不变 |
| 快照时机 | 打开命名框后阅读位置变化，保存的仍是点击添加时的位置 |
| 校验与提交 | 空白和超长名称不可保存；中文、emoji 可保存；重复点击保存只有一条记录 |
| 同名 / 位置去重 | 不同位置允许同名；同一位置重复或并发添加仅保留一条记录 |
| 同章及跨章跳转 | 均定位到保存的正文位置；重复跳转有效；最近一次点击胜出 |
| 三种模式及重排 | 各模式创建、互相切换后跳转有效；字体或屏幕大小变化后目标文字仍在可见区域 |
| 图文及边界 | 章节开头、结尾、图片块和无目录书均可记录并返回 |
| tab 与列表 | 当前书隔离、排序稳定、独立滚动；原目录高亮及 fragment 跳转无回归 |
| 重命名 / 删除 | 名称更新且顺序不变；取消删除保留，确认后删除；菜单不触发跳转 |
| 持久化与级联 | 重启后保留；删书后无遗留书签；其他书数据不受影响 |
| 错误处理 | 写入失败可重试；目标失效或加载失败保留原位置与记录；读取错误区别于空列表 |
| 朗读 | 当前书跳转时暂停且不被自动拉回；主动恢复播放从新位置开始 |
| 迁移 | Room 验证 `2 → 3`、`1 → 3`，保留原数据，并验证索引和外键级联 |

测试分工：DAO/迁移使用数据库 instrumentation test；名称校验与目标解析使用单元测试；新增、tab、管理及同章跳转使用 Compose UI test；三种模式重排后的定位及朗读联动补充设备验收。

## 7. 完成标准

上述交互和验收项全部满足，schema 与 AutoMigration 可通过 Room 校验，现有目录和阅读进度行为无回归。交付实现时附实际运行的测试结果及设备验收记录。
