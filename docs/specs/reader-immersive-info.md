# 沉浸阅读信息栏 Spec

状态：已实现，验证记录见文末  
日期：2026-10-11

## 1. 目标与范围

用户隐藏阅读控制栏、进入沉浸阅读后，无需打开菜单或拉出系统状态栏，即可查看当前章节、章内页数、时间和手机电量。信息应清晰但弱于正文，不遮挡内容，不影响翻页、滚动或朗读跟随。

首版默认开启，覆盖横向分页（PAGED）、仿真翻页（FLIP）、滚动（SCROLL）三种阅读模式。页数采用「当前章第几页 / 当前章总页数」；滚动模式没有稳定的页面边界，改为显示「本章进度百分比」。分页模式的信息属于书页内容，随书页平移或卷曲；滚动模式保留固定信息区域。

首版不增加设置开关、全书页码、剩余阅读时长、电池预警、点击信息栏跳转等功能，不变更现有系统导航栏策略。

## 2. 现有实现依据

- `ReaderScreen.kt` 通过 `controlsVisible` 控制上下工具栏；为 false 时隐藏系统状态栏。章节名称目前位于顶部工具栏，底部的 `章节序号 / 章节总数` 不是页码。
- `PagedReader.kt` 与 `FlipReader.kt` 使用 `rememberChapterPages` 计算当前章及相邻章分页，局部持有实际页索引，目前仅向上回传正文进度。
- `chapterPageWindow` 会在当前章两端拼接上一章末页、下一章首页；该窗口索引及长度不能直接当作章内页码及总页数。
- `VerticalReader.kt` 基于首个可见正文块回传章内进度，此进度是正文位置映射，并非滚动距离百分比。
- 三种阅读器当前使用左右 22dp、顶部 84dp、底部 92dp 留白；分页高度扣除 176dp。滚动模式的 `contentPadding` 随内容滚动，不能单独保证常驻信息栏不遮挡正文。
- `ReaderPalette` 已有背景、正文和弱化文字颜色，可复用现有阅读主题。

## 3. 布局与显示

沉浸状态示意（框线仅表示屏幕范围，不绘制到产品中）：

```text
┌────────────────────────────────┐
│ 第十二章 山雨欲来                │
│                                │
│ 正文内容……                     │
│                                │
│ 本章 3 / 18 页    22:08  ▰ 76%   │
└────────────────────────────────┘
```

滚动模式底部左侧替换为 `本章 42%`。

| 区域 | 内容 | 展示规则 |
| --- | --- | --- |
| 顶部左侧 | 当前章节标题 | 一行，超长尾部省略；空白标题回退为「第 N 章」，N 为阅读序列中从 1 开始的章节序号 |
| 底部左侧 | 页码或章内进度 | 分页：`本章 3 / 18 页`；滚动：`本章 42%` |
| 底部右侧 | 时间、电池图标及百分比 | 时间遵循系统 12/24 小时制，12 小时制保留上午/下午标识；不显示秒；充电时图标带充电标识 |

- 背景与阅读背景一致，无分割线、阴影、卡片或额外装饰。文字和图标使用 `palette.muted`，必要时调整以保证可读性，不额外降低透明度。
- 文字基础字号 12sp，跟随系统字体缩放；不随正文阅读字号变更。左右基准间距 22dp，顶部和底部信息行最小高度 24dp。
- 信息区域避让刘海、挖孔、横屏侧边遮挡和系统导航区。安全区域由统一布局计算，避免父子组件重复添加 Insets。
- 正文布局为信息区域保留固定空间。控制栏显隐、系统状态栏短暂浮现以及时间和电量变化，均不得改变正文可用尺寸或触发重新分页。
- 优先使用已有上下留白容纳信息区域，不简单在 84dp/92dp 基础上再叠加一层完整边距；空间不足时统一调整正文视口。滚动正文须在信息区域之间裁剪，不能只依赖列表首尾 padding。
- 横屏、小窗口或较大系统字体导致底部一行放不下时，底部使用两行：第一行页码/进度，第二行时间与电量；按当前尺寸和字体预留稳定高度，不按实时字符串长度切换布局。不得丢弃时间、电量或页码字段。

## 4. 状态与交互

### 4.1 显示条件

- 正文可读且 `controlsVisible == false` 时显示信息栏。进入阅读器时保留现有控制栏初始状态，不额外改变进入沉浸模式的操作。
- 点击正文唤出工具栏时隐藏信息栏；再次隐藏工具栏时恢复。显隐可使用轻微淡入淡出，正文始终不位移，工具栏与信息栏不得叠字。
- 首次加载及无可读正文的错误页不显示信息栏。章节切换期间，若仍显示旧正文，则保留与旧正文匹配的章节和进度；若正文已清空，则隐藏章节及进度，时间与电量可以保留。
- 新章节正文与新章节信息应一起生效；不得出现「新章节名 + 旧页码」。分页结果尚未就绪时显示 `本章 — / — 页`，不伪造 `1 / 1`。
- 信息栏不提供点击行为、不拦截原阅读手势。正文区域的点按、滑动、边缘翻章和朗读跟随保持现有行为。信息区域的触摸交给原阅读器手势处理；系统手势区域保持系统优先。
- 系统状态栏通过边缘滑动短暂浮现时，允许覆盖顶部信息区域；正文和页码保持稳定，状态栏收起后恢复完整可见。

### 4.2 页码与进度口径

- PAGED 与 FLIP 的页码直接来自本次排版结果及已完成翻页的位置，从 1 开始，总页数仅计算当前章，不含相邻章预览页。
- 拖动或翻页动画期间，当前页与目标页各自显示所属章节及章内页码，信息随各自书页一起移动或卷曲；取消时随原书页返回。阅读位置仍在翻页完成后更新。跨章预览页也必须使用来源章节的标题和页码，不能出现 0 页或超出总页数。
- 字号、行距、屏幕尺寸或阅读模式变化可能改变总页数。先按现有正文定位机制恢复位置，再发布新页码；不承诺保留旧页码，不把页码作为持久化位置。
- 目录跳转、书签跳转、恢复阅读和 TTS 自动跟随均更新到实际显示的稳定页面。TTS 在后台或用户暂停跟随时，显示用户正在看的正文位置。
- SCROLL 使用阅读器当前可见正文位置的章内进度，夹取到 0–1 后向下取整为百分比；到达章节可滚动终点时显示 100%，整章无需滚动即可显示完整时也显示 100%。无效或尚未就绪的进度显示 `本章 —%`。此值仅用于展示，不为显示 100% 而修改持久化阅读定位。
- 成功排版的空章节按现有阅读器实际可展示结果处理；仅在确实存在一个可展示页面时显示 `1 / 1`。

### 4.3 时间与电量

- 进入前台时立即读取当前本地时间和电量。前台时间按分钟更新，响应系统时间、时区和 12/24 小时制变化；从后台返回先刷新，不等下一分钟。
- 电量显示整数百分比 0–100%，基于系统报告的 level/scale 计算并夹取合法范围；充电状态变化及时更新。未获得数据或 scale 无效时显示电池图标与 `—%`，不把未知值展示为 0%。
- 电量通过系统事件更新，不高频轮询；时间无需每秒刷新。不请求额外运行时权限，不启动后台服务。
- 仅在阅读页前台且信息栏需要显示时订阅更新；隐藏信息栏、阅读页停止或离开阅读页时停止定时任务并释放订阅。再次显示时先刷新快照，避免旧值闪现。

## 5. 实现建议

1. `ReaderInfoLayout` 统一提供安全区域和单份设备状态订阅。PAGED 在每个 pager item 内绘制 `ReaderPageInfo`；FLIP 在每页内容中绘制并纳入翻页纹理。时间与电量事件允许刷新页面纹理，但不触发重新分页或重置翻页状态。SCROLL 保留固定信息区域。
2. 引入阅读展示快照（如 `ReaderDisplayInfo`），至少包含书籍与章节标识、章节标题、阅读模式、可空的章内页码/总页数或进度，以及内容/排版代次。由阅读器输出实际展示状态，而非根据 `chapterFraction × pageCount` 推算。
3. 为分页及仿真翻页添加展示状态回调。跨章窗口条目补充或关联源章节标识、章内页索引与总页数；保留现有用于首屏排版的可空标题语义，信息栏标题应独立获取，不能因为非首页而丢失章节名。
4. 回调携带章节及排版代次，父层忽略已过期内容的回调；章节标题、页码和总页数作为同一份快照更新，避免异步加载、快速跳转及重排造成串章。
5. 滚动阅读器沿用可见正文位置回调，另提供到达末尾状态用于显示百分比。统一正文视口后同步校正可见位置计算、书签恢复和 TTS 跟随。
6. 抽取共享的正文与信息栏布局尺寸，分页测量与实际渲染使用同一视口；上一章/下一章预排版也使用相同尺寸。尺寸不依赖工具栏可见状态或时间、电量的内容。
7. 设备状态独立于正文状态更新，使用生命周期感知的订阅。时间跳变与电量广播仅更新信息栏，不重新加载章节、不写入阅读进度、不重置分页或滚动状态。

本功能不新增持久化配置或数据库字段，无需 Room schema 变更或迁移。具体系统 API 的注册方式在实现时按项目目标 SDK 核对。

## 6. 验收标准

| 场景 | 预期结果 |
| --- | --- |
| 三种模式进入沉浸状态 | 章节、页码或章内进度、时间、电量同时可见，系统状态栏保持现有隐藏行为 |
| 唤出/隐藏工具栏 | 信息栏按规则切换，当前正文位置和分页总数不变，无重叠文字 |
| 分页章首页、中间页、末页 | 正确显示 `1 / N`、`k / N`、`N / N`，不计相邻章预览页 |
| 向前/向后跨章、取消翻页 | 完成后匹配目标章首页/末页；取消后保持原信息，无 0 页、越界或串章 |
| 字号/行距调整、横竖屏切换 | 恢复正文位置后更新页数，测量与渲染一致，无信息栏遮字 |
| 长章名、无标题、图文混排、空章节 | 标题省略/回退正确，页码符合实际分页结果，未知状态不伪造数字 |
| 滚动至章首、中间、章末及短章节 | 百分比按定义展示，末尾和完整可见短章节为 100%，滚动正文不穿过信息栏 |
| 目录/书签跳转、恢复阅读、TTS 跟随 | 信息匹配实际可见正文；关闭跟随后不追随后台朗读位置 |
| 快速跨章、加载延迟、加载失败 | 旧正文只搭配旧信息，目标正文就绪再切换，过期回调不污染显示 |
| 分钟变化、改时区/时间制、充电/拔电 | 无需操作阅读页即可刷新，后台恢复立即更新，无多余权限弹窗 |
| 时间与电量刷新 | 页码、正文位置不变，不触发重新分页、章节加载或阅读进度写入 |
| 所有阅读主题、横屏、小窗口、大字体 | 信息可读，安全区域正确，底部必要时两行展示且字段完整 |
| 反复进入退出阅读器及前后台切换 | 无重复订阅、计时任务泄漏或后台持续刷新 |
| TalkBack | 可读完整章名、「本章第 3 页，共 18 页」、时间及「电量 76%，充电中」；不因每分钟更新主动打断正文朗读 |

实现阶段测试重点：章内索引映射和跨章边界、回调代次过滤、未知设备状态与格式化，以及三种模式下的布局/手势回归。使用可控时间和电量输入验证设备信息刷新；设备上检查刘海屏、手势导航和三键导航。

## 7. 实现与验证记录（2026-10-11）

- `ReaderInfo.kt` 提供共用信息栏、稳定安全区域、窄屏两行布局、时间/电量生命周期订阅及无障碍描述。工具栏退出动画结束后显示信息栏。
- 三种阅读器共享正文边距；滚动正文在固定区域裁剪。分页窗口条目携带来源章节的完整标题、页码与页数；信息栏进入每页内容和仿真翻页纹理，随页面翻动。
- 每次切换书籍、章节内容、设置或跳转时创建独立展示状态容器，旧内容回调无法覆盖新容器；尺寸变化通过分页器重建及对应 effect 取消处理。
- `:app:testDebugUnitTest`：39 项通过，包括新增的跨章页码、电量边界、滚动进度测试。
- `:app:connectedDebugAndroidTest`：Pixel 8 Pro API 35 模拟器上 21 项通过，覆盖分页/仿真翻页信息、信息栏显隐与正文范围、短章进度，以及原有跨章、书签、滚动手势与数据库回归。
- 工具栏动画收尾调整后，额外通过 3 项书签/阅读页集成测试；三种模式均执行实际沉浸切换断言并完成截图检查。截图位于本地 `build/reader-info-verification/`，不纳入版本控制。
- 实机刘海/三键导航组合、系统时间与时区修改、充拔电及 TalkBack 人工验收仍需补充；当前验证不代表已覆盖全部设备组合。

### 页内信息调整

- 按用户要求，将分页与仿真翻页的信息移入每张书页；跨章拖动时两侧各自显示所属章节信息。滚动模式仍使用固定信息区域。
- 仿真翻页的预渲染页不重复暴露信息栏无障碍节点；时间、电量及显隐变化同时触发页面纹理刷新。
- 调整后通过 39 项单元测试、22 项模拟器测试；最终纹理刷新调整通过 8 项阅读页专项测试，并检查了页内信息截图。
