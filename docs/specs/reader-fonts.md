# 阅读字体选择与导入 Spec

状态：已实现；设备验证结果与未覆盖范围见[验证记录](../reader-font-verification.md)

日期：2026-11-15

## 1. 目标与范围

用户可以选择阅读字体，使用随应用内置的三款中文字体，或通过系统文件选择器导入自己的字体。选择结果本地持久化，适用于所有书籍和滚动（SCROLL）、左右分页（PAGED）、仿真翻页（FLIP）三种阅读模式。

### 1.1 首版包含

- 保留「系统默认」，新安装和旧版本升级后均保持现有字体外观。
- 内置「朱雀仿宋」「寒蝉端黑宋」「霞鹜文楷」，随安装包分发，首次启动断网也可使用。
- 从文件单个导入静态 TTF / OTF 字体，支持预览、选择、删除导入字体。
- 切换字体时重新排版并恢复正文位置，不以原页码定位。
- 字体加载失败回退、重复导入处理。
- 独立「关于」页面，统一展示内置字体及随包第三方库的作者、LICENSE 和链接。

### 1.2 首版不包含

字体商店、在线下载/更新、批量导入、压缩包解压、字体导出/分享、云同步、逐书配置、分别设置标题/正文字体、字重选择、可变字体轴设置、TTC/OTC 字体集合及 WOFF/WOFF2。用户导入字体不上传服务器，不安装为系统字体，也不改变应用整体 UI 字体。

本规格中的格式、容量和交互细节为已确认的首版实现依据。实际验证范围单独记录，不将未执行的设备组合或故障注入视为通过。

## 2. 现有实现依据

- [ReaderSettings](../../app/src/main/java/top/ntutn/sonovelreader/data/Models.kt) 已定义字号、行距等全局阅读设置，尚无字体标识。
- [SettingsRepository](../../app/src/main/java/top/ntutn/sonovelreader/data/SettingsRepository.kt) 使用 Preferences DataStore 保存阅读设置，可扩展字体选择，无需变更书库数据库。
- [SettingsScreen](../../app/src/main/java/top/ntutn/sonovelreader/ui/SettingsScreen.kt) 为「阅读设置」页，现有字号上方适合放置「阅读字体」入口。
- [readerTextStyle](../../app/src/main/java/top/ntutn/sonovelreader/ui/ReaderTheme.kt) 尚未指定 `fontFamily`，可作为三种模式共享的正文样式入口。
- [rememberChapterPages](../../app/src/main/java/top/ntutn/sonovelreader/ui/ReaderChapterPages.kt) 使用 TextMeasurer 测量正文和章首页标题，并缓存分页结果；测量、实际绘制和相邻章预排版必须使用同一已解析字体。
- 当前最低 Android 版本为 API 29，可基于 Android 字体加载 API 与 Compose FontFamily 实现；具体适配方式在实现阶段验证。

## 3. 内置字体及分发约束

| 展示名称 | 稳定 ID | 上游来源 | 首版资源选择 |
| --- | --- | --- | --- |
| 系统默认 | `system` | Android / Compose 默认字体 | 不打包资源，维持当前默认行为 |
| 朱雀仿宋 | `builtin:zhuque` | [TrionesType/zhuque](https://github.com/TrionesType/zhuque) | 官方发布的常规静态字重 |
| 寒蝉端黑宋 | `builtin:chill-duan-hei-song` | [Warren2060/ChillDuanHeiSong](https://github.com/Warren2060/ChillDuanHeiSong/) | 官方发布的 Regular 或等效常规静态字重 |
| 霞鹜文楷 | `builtin:lxgw-wenkai` | [lxgw/LxgwWenKai](https://github.com/lxgw/LxgwWenKai) | 原仓库非等宽 Regular 静态版，不擅自替换成 Lite / Screen / GB 等衍生版 |

三款字体均采用 SIL Open Font License 1.1：依据[朱雀仿宋说明](https://github.com/TrionesType/zhuque#许可证)、[寒蝉端黑宋许可证](https://github.com/Warren2060/ChillDuanHeiSong/blob/main/LICENSE)、[霞鹜文楷授权说明](https://github.com/lxgw/LxgwWenKai#授权信息)。分发时以所选版本附带的实际许可证为准。

实施要求：

1. 资源入库时固定 release tag 或 commit、原始下载 URL、文件名、字节数、SHA-256、版权声明及许可证全文，不使用运行时或构建时的「latest」下载。
2. 原样分发官方字体，首版不自行裁字、修改轮廓或转换格式，避免缺字、保留名称及衍生授权风险。若上游仅提供集合或可变文件，须先选定可用官方静态版本，不静默替换字体。
3. 每款只打包一个正文常规字重；标题沿用现有加粗策略，测量与绘制使用一致的字重/合成策略，不额外打包整套字重。
4. 不设独立「字体来源与许可」页面；字体与第三方库统一在独立「关于」页面展示名称、版本、作者/版权、LICENSE 全文和上游链接，详见 4.5。外链只在用户点击时打开。
5. 记录三款资源原始总大小、release APK 增量及设备安装占用。体积过大时提交取舍，不将内置改为首次联网下载，也不未经确认改用精简字库。
6. 实际资源版本、文件名、原始来源、字节数和校验值已固定于[资源清单](../../app/src/main/assets/fonts/manifest.json)；配对构建的包体增量见[验证记录](../reader-font-verification.md)。

## 4. 界面与交互

### 4.1 入口与字体列表

在阅读设置页、字号设置之前新增一行：

```text
阅读字体                 系统默认  >
```

点击进入「阅读字体」子页，系统返回回到阅读设置；沿用现有导航，不新增阅读工具栏快捷入口。页面结构：

```text
< 阅读字体                       导入字体

预览
山色入帘青，灯下读书声。
春风又绿江南岸。0123456789 Aa，。！？

系统默认                            ✓
内置字体
  朱雀仿宋
  寒蝉端黑宋
  霞鹜文楷
我的字体
  示例字体 Regular                  ⋮
```

- 单选列表：系统默认在首位，内置字体按上表顺序；导入字体按导入时间倒序，同时间按 ID 排序。空列表提示「还没有导入字体，支持 TTF、OTF」。
- 字体名称、操作按钮和错误提示始终使用应用 UI 字体，避免导入缺字字体后无法操作；统一预览区域使用所选字体，不在每行同时加载大字体文件。
- 预览使用当前阅读字号、行距、段间距、首行缩进和阅读主题；容器支持滚动，不截断大字号文本。
- 点击项目先解析字体，成功并保存后更新选中态与预览，留在本页便于比较，无需额外「应用」按钮；返回不撤销已生效选择。
- 加载中显示目标行进度状态，保留原字体与预览；失败提示「字体加载失败，请重试或选择其他字体」，原选择不变。选择保存失败同样不发布成功状态。
- 快速连续选择以最后一次为准，过期加载结果不得覆盖较新选择。点击当前已生效项不重复写设置或触发重排。
- 字体列表读取失败独立显示错误与重试，不把失败视为空列表。系统默认和内置列表仍可操作。
- 行触控目标至少 48dp；TalkBack 可读名称、来源及选中状态。大系统字号、横屏和窄屏下操作可达，长名称允许省略并提供完整无障碍文本。

### 4.2 从文件导入

1. 点击「导入字体」通过 Storage Access Framework `OpenDocument` 选择单个文件，不申请存储或「所有文件访问」权限。
2. 说明支持 `.ttf` / `.otf`，优先使用字体 MIME；提供「所有文件」选择兼容部分文档提供器的错误 MIME，不能仅凭扩展名或 MIME 放行。
3. 用户取消时无写入、无错误提示；选择后显示「正在导入」，禁止重复发起导入，但不阻塞返回操作。
4. 在 IO 线程从 URI 流式复制到应用私有临时目录，同时计算 SHA-256 和实际字节数；不依赖文件提供器给出的名称、路径或大小。单个文件上限 50 MiB（52,428,800 字节），读到上限之外立即停止，未知大小同样受限。
5. 验证 SFNT 签名与必要表结构，拒绝集合、网页格式和包含可变轴的字体，再用平台字体 API 实际构建并测量样例文本。异常受控处理，格式有效不等于保证覆盖所有汉字。
6. 名称优先读取字体的 family/subfamily 元数据，失败使用去扩展名的文件名，再失败用「导入字体」。清理控制字符和路径字符、限制展示名称长度为 80 个 Unicode 码点；名称只用于展示，不用作磁盘路径或主键。
7. 校验成功后将文件移动到私有正式目录，并持久化目录记录；全部完成才显示「字体已导入」，新增列表项但不自动切换，用户点击后应用。
8. 导入过程失败清理临时文件，不留下可选择的半成品，不改变当前阅读字体。离开页面或进程中断后，下次启动可清理未完成临时文件，不在后台长期保留导入任务。

正式文件复制后不依赖原 URI，不需持久化外部读取授权；原文件移动、删除或文档提供器撤销权限，不影响已导入字体。

### 4.3 去重、同名与错误提示

- 按完整文件 SHA-256 去重。重复导入已有自定义字体时提示「该字体已导入」，定位已有项，不新增、不自动应用。
- 与已内置资源哈希一致时提示「该字体已内置」，定位对应内置项；文件不同但名称相同允许共存，辅助显示原文件名和哈希短码以区分。
- 同名字体的新版本不覆盖旧文件，作为新项导入；不提供原地替换，避免当前字体资源在重排中被修改。
- 错误分类至少覆盖：不支持格式、空文件/损坏文件、超过 50 MiB、来源无法读取/授权失效、存储空间不足、字体无法加载、目录写入失败。
- 对用户显示可理解的中文提示，不展示堆栈或私有路径；日志不记录 URI 授权信息，不将字体样本或文件上传。
- 导入前提供简短说明：「仅在本机使用，请确保拥有字体使用权。」不要求用户将个人字体按 OFL 再授权。

### 4.4 删除导入字体

- 只有「我的字体」提供「删除」菜单，系统默认及内置字体不可删除；首版不提供重命名。
- 确认文案：「删除字体『名称』？此操作不会删除原始文件。」正在使用时补充「删除后将改用系统默认」。
- 删除非当前字体不触发阅读器重排；取消不改变任何内容。
- 删除当前字体时，先确保系统默认加载及选择持久化成功，再移除目录记录并清理字体文件与缓存；默认切换失败则保留该字体，不执行删除。
- 删除文件失败不报告完整删除成功：可先从目录移除并记录待清理文件，提示「字体已移除，文件清理将在下次启动重试」。重新启动后不能恢复成可选项。
- 文件只能在受控字体目录内按内部 ID 删除，不接受元数据或外部文件名提供的路径；不删除原始导入文件。

### 4.5 独立「关于」页面与统一第三方声明

- 阅读设置页新增独立「关于」入口，与「阅读字体」并列；不放在字体子页内，不为字体单独设置来源/许可页面。返回后保留原阅读设置状态。
- 「关于」页展示应用名称、版本，以及「内置字体」「第三方库」两个分组，统一承载作者致谢、来源和授权信息。页面使用应用 UI 字体，不受阅读字体设置影响。
- 每个条目至少展示：项目/字体名称、实际随包版本、作者或维护组织、版权声明、LICENSE 名称/标识（如 `SIL OFL 1.1`、`Apache-2.0`），以及项目主页/源码仓库和上游 LICENSE 链接。
- LICENSE 全文和上游要求的 NOTICE/署名声明随包保存，在关于页内展开查看，支持滚动和文本复制，离线可读；不能仅以外部链接或通用许可证模板代替实际版本的授权声明。多个许可证或附加声明应完整列出，不合并丢失版权信息。
- 第三方库清单依据实际 release 运行时依赖及随包代码/资源生成并人工核对，包含直接依赖、传递依赖及本地引入的第三方模块；仅构建/测试使用且未分发的工具不作为运行时组件混入。不同组件不能仅因许可证相同而丢失各自作者与来源。
- 元数据缺失时在构建准备阶段补齐，不能把未知作者或许可证猜成确定信息；发布前核对实际版本及授权义务。依赖新增、升级或移除时同步更新清单和离线文本，清单不得仅覆盖本次新增字体。
- 内置字体作为应用分发资源列入关于页；用户私有导入字体不作为应用分发组件加入公共致谢清单，不自动联网查询其作者或 LICENSE。
- 点击外链才交由系统浏览器打开；断网或无可处理应用时提示且保留关于页。名称、作者、版本和 LICENSE 全文始终可离线查看，链接提供可复制文本。
- 关于页支持长列表、长许可证、大系统字号及 TalkBack；展开某条许可证不改变字体选择或阅读位置。

## 5. 阅读器生效规则

### 5.1 作用范围

所选字体应用于正文文本及正文区域的章首页标题，保留现有字号、标题字号倍率、缩进、行距和段间距。书架、设置、目录/书签列表、阅读控制栏、沉浸信息栏、页码、时间、电量、图片及图片占位文案保持原有 UI 字体与行为。

缺字交由 Android 系统字体回退，西文、标点、emoji、繁体字及生僻字不得因手工过滤或替换而丢失。不承诺所选字体覆盖全部字符；系统也缺少字形时按系统缺字行为展示，不将单个缺字视为整个字体损坏。

### 5.2 重排与定位

- 字体解析完成后，以同一份有效字体快照驱动正文、章首页标题、TextMeasurer 和所有模式；不能先用旧字体分页，再用新字体绘制。
- 字体 ID、资源版本/哈希、解析成功状态纳入排版缓存失效条件。当前章、相邻章预排版和 FLIP 页面纹理同时失效，避免新旧字体混用。
- 在切换前捕获当前书、章和可见正文位置；滚动模式恢复到该位置附近，分页/仿真翻页恢复到包含该位置的页面。不保留旧页号或精确像素，不能跳回章首或误跨章。
- 沿用正文定位模型；若现有回调仅提供页首粒度，则以切换前稳定可见页的正文起点为锚。保存书签仍以正文位置为准，不修改既有书签记录。
- 重排期间忽略旧布局进度回调，不把中间空页、默认第一页或过期结果写入阅读进度。新布局完成并定位后，再恢复位置上报和页码发布。
- 尚未就绪时保持旧字体的完整页面或显示加载状态，不把新选择与旧排版页码组合发布。最终以最新字体选择和最新主动跳转请求为准。
- 字体切换不重载书籍内容、不重置阅读主题或其他设置；已生效字体重启后保持。首次恢复阅读先解析字体再稳定排版，避免先显示系统字体后跳动。
- 不因字体变更停止或重启 TTS，也不改变语音、速率和音调。启用朗读跟随时在重排完成后定位到最新朗读位置；未跟随时保持用户视口，不被后台朗读拉回。
- 字体解析后仍出现运行时加载错误时回退系统默认、清理相关缓存并按相同规则重排，提示一次「所选字体不可用，已使用系统默认」，不陷入重试/重排循环。

## 6. 数据与架构建议

### 6.1 设置与字体目录

- `ReaderSettings` 增加 `fontId: String = "system"`；Preferences DataStore 增加 `reader_font_id`，仅保存稳定 ID，不保存 URI 或绝对路径。旧版本无键时默认 `system`，其他设置不变。
- 内置字体目录为编译期清单，包含 ID、名称、资源定位、版本、哈希、字重及许可证信息，ID 不随文件名或版本更新改变。
- 自定义字体 ID 使用 `imported:<uuid>`；文件保存到 `noBackupFilesDir/fonts/<uuid>.<ttf|otf>`，不直接使用外部路径。
- 自定义目录建议使用独立、带版本号的原子 JSON 文件，与字体一起放入 no-backup 区域。记录 `id`、展示名、原文件名、受控相对文件名、SHA-256、字节数、导入时间及格式；文件不可变，更新通过新增记录完成。
- 目录损坏不是空目录：保留原始目录供诊断，提示读取失败并提供重试；不擅自批量删除正式字体文件。孤儿清理必须在目录成功读取并核对后执行。
- 本功能不新增 Room 表，不需要数据库 schema 升级；若实现改变此决策引入 Room，迁移优先使用 AutoMigration，并另行更新规格。

### 6.2 仓库与一致性

新增独立字体仓库负责目录观察、导入、去重、删除、资源解析和有效性检查；设置仓库继续保存选择。UI 不直接操作文件，ViewModel 输出列表、操作状态及一次性提示。

文件系统和 DataStore 不能跨存储事务，采用串行操作与可恢复提交顺序：

1. 导入：临时文件 → 校验 → 正式文件 → 原子写目录；目录写入失败回收本次新增文件，失败回收标记重试。
2. 选择：验证并解析目标 → 持久化 ID → 发布已生效快照；处理并发时保证最后一次有效请求胜出，失败不损坏原选择。
3. 删除：必要时持久化系统默认 → 原子移除目录项 → 清理文件；中断后允许遗留待回收文件，不允许目录长期引用已主动删除的文件。
4. 启动：协调目录与选择；未知 ID、文件缺失或损坏时恢复为 `system` 并修复设置，一次提示，不丢失其他导入记录。短暂 IO 错误与永久损坏区分，不因一次失败自动删除用户文件。

字体文件、目录和解析缓存不参与云备份或设备迁移。选择 ID 可能随现有设置恢复，找不到对应自定义资源时按上述规则回退；用户重新导入即可，不尝试访问旧设备 URI。使用 no-backup 目录避免大字体占用自动备份额度。

### 6.3 性能与安全

- 文件读取、哈希、元数据检查和字体构建不在主线程执行；按需加载，不在启动时同时解析所有导入字体。
- 缓存按 ID 与资源版本/哈希索引，采用有限容量策略；切换和删除后释放过期引用，禁止无限保留所有字体及分页纹理。
- 限长、限量和平台解析失败均应可控；不能通过扩展名判断安全，也不承诺通过应用校验即可识别所有恶意字体。使用系统解析器，不引入不必要的自定义原生解析库。
- 首版不设导入数量硬限制，磁盘写入失败可恢复；记录参考设备上首次加载、连续切换和大字体导入的耗时及内存，要求无 ANR、崩溃或明显主线程阻塞。
- 新增源码与文档按职责拆分，单个文本文件遵循项目 500 行限制。

## 8. 实施顺序与完成标准

1. 固定三款官方资源与版权许可，建立可复现清单并评估包体。
2. 实现字体目录、私有文件管理、加载解析、持久化选择与中断恢复测试。
3. 实现字体子页、预览、文件选择、错误反馈及删除；新增独立关于页，整理全部随包第三方库与字体的作者、LICENSE/NOTICE 和链接，提供离线展示。
4. 接入共享正文样式、标题测量、三种阅读器及缓存/定位机制。
5. 执行上表验收与回归，记录实际字体版本、包体增量、性能及设备验证结果。

完成标准：三款字体随包离线可用，用户字体可安全导入/选择/删除，持久化和失败恢复可靠；三种模式字体一致、阅读位置不丢失，现有书签、朗读、翻章和信息栏无回归，独立关于页统一展示字体及第三方库的作者、LICENSE 和链接，授权全文与必要 NOTICE 随包完整可查看。
